# 01 — ギルドの仕組み（体制の型）

1人のユーザー＋複数のAIエージェントで回す「個人用マルチエージェントシステム」の体制。
実運用（2026-08月時点・2ワークスペース並行）で固まった型だけを書く。設計上の理想は書いていない。

## 構造は5階層。箱では採番しない

```
WS（ワークスペース）＞ 箱 ＞ 案件 ＞ トラック ＞ セッション
```

- **箱** = 用途カテゴリの棚（例:「学習」「開発」）。**採番しない**
- **案件** = 何をやるか。台帳1枚と1対1
- **トラック** = 案件上の採番の連なり（S1→S2→…の作業レーン）
- **セッション** = 1会話・使い捨て。**状態はセッションに持たせず台帳へ永続化する**

箱で採番すると、箱内の別案件が動いたときS番号が混線する（実際に踏んだ）。
採番は必ず案件単位。改名時は旧名を alias に残して地図を割らない。

## 役割は3つ

```
ユーザー（最終判断・用語確定・改名は必ずここを通す）
   │
   ├─ 司令塔トラック（WS名 S〈n〉）… 運営。采配・棚卸し・用語確定・優先度。実作業禁止
   ├─ 作業トラック（案件ごと）   … 建設。実装・調査。案件台帳と1対1
   └─ 実行部隊（ローカルLLM等）  … 依頼を受けて動く。agent_job台帳で見える化
```

- **司令塔の実作業禁止**は効く。手を動かさない役を1枠作ると判断が1か所に集まり全トラックが軽くなる（実測）。
  例外はユーザー指示があるときのみ
- 司令塔の成果物は**発注**（依頼票を書く）。抱え込まない
- 定例は「作業日の頭に軽量版5〜10分（発注消化・滞留・依頼票チェックのみ）」＋滞留が溜まったらフル定例

## 通信は4経路

| 経路 | 性質 | 実装 |
|---|---|---|
| ① 依頼票（📨申し送り） | 宛先あり・非同期・**消化で消える** | 相手台帳の📨欄に直接書く（WS横断も同じ） |
| ② 台帳 pull | 隣の現在地を読みに行く・pushなし | 台帳の「現在地」セクション |
| ③ 回覧板／索引昇格 | 宛先なしの全体周知（軽）／恒久ルール（重・司令塔承認制） | BULLETIN.md／MEMORY.md |
| ④ ライブボード | リアルタイム稼働状態 | session_state＋agent_jobs を10秒毎描画 |

①〜④が「会話」、agent_job台帳が「仕事」。
セッション同士が同時に起きていなくても、台帳の📨欄だけで要望→実装→返信が1日で回る（実測: 同日3往復）。

## 道具3点セット（覚え方: ボード＝いま／マップ＝ぜんたい／カウンター＝紙）

| 道具 | 役割 |
|---|---|
| エージェントライブボード | いま動いているセッション🟢🟡🔴＋⏳委託中（実行部隊バッチ）の監視 |
| エージェントマップ | 案件×トラックの俯瞰・棚卸し（静的ダッシュボード） |
| エージェントカウンター | 各台帳の近況・依頼票・回覧板をファイルを開かずに読む窓口 |

## 実運用の学び（持ち出し可能なコア）

- **状態はセッションに持たせない**。セッションは使い捨て・正本は台帳1枚。ビューアは毎回ファイルから描画（コピー保持＝二重管理は禁止）
- **運用が毎日エッジを吐く構造を先に作る**。外部データ取り込みやグラフDBから始めない。依頼台帳が最初の実データ。Neo4j等の重装備は「要ると分かってから」
- **状態と実績を分ける**: いま=1ジョブ1JSON（上書き・prune あり）／実績=history.jsonl（追記専用・prune なし）
- **台帳配線はバッチを絶対に殺さない**: import失敗はNone・呼び出しは握りつぶしラッパー・追記はベストエフォート
- **stale検知は「最終更新の途絶」**で。heartbeatが粗いバッチは stale_sec を明示（既定のままだと健全でも誤警報）
- **Windows日本語環境の地雷**: バッチ起動側に `PYTHONIOENCODING=utf-8` 必須＋スクリプト側 `reconfigure(errors="replace")` の二段構え／venv の python.exe はシム＝1バッチが2プロセスに見える（二重起動と誤診しない）
- **LLM実行部隊の統率**: 失敗は「形式・知識・性格」の3層で診断すると処方が決まる。
  薬は2本 — 知識カード注入（正しい事実データを持たせる）と「構造で外す」（事実をLLMに書かせずコードで埋める。
  渡していない情報は捏造しようがない）。審判はLLMでなく機械カウント
- **改名のコスト管理**: 概念の名前は変える・ファイル名/ディレクトリ名は据え置き・alias で過去と接続
- **運用してみて初めて概念の境界が見つかる**（「箱で採番しない」等は設計先行では出てこなかった）

## 用語ミニ集

**依頼**（仕事の1単位・宛先不問）／**委託**（依頼が自コンテキストの外で走行中）／
**実行部隊**（受けて動く側）／**依頼票**（宛先あり・消化で消える）／**回覧板**（宛先なし・読めば終わり）／
**台帳**（案件の正本1枚）／**索引**（MEMORY.md。全セッションが毎回読む＝載せるものは司令塔承認制）／
**🌱仮置き**（新語はどのセッションも自由に仮置き→確定は司令塔定例のみ）
