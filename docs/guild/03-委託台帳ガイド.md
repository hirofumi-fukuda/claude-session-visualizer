# 03 — 委託台帳ガイド（agent_job）

Claude セッションとして見えない「委託仕事」（ローカルLLMバッチ・夜間処理等）を
`~/.claude/hooks/agent_jobs/<job_id>.json` に1ジョブ1ファイルで記録し、
ライブボードの「⏳委託中」セクションに出す仕組み。死んだジョブに気づけるのが最大の価値。

## 使い方

CLI（シェル/batから）:
```
python agent_job.py start --title "夜間バッチ" --project "案件名" --agent "ollama:モデル名" \
       [--total 25] [--job-id nightly-batch] [--stale-sec 5400]
python agent_job.py progress <job_id> [--cur 3] [--note "処理中の対象"]
python agent_job.py done <job_id> [--summary "25件完了"]
python agent_job.py fail <job_id> [--summary "接続不可"]
python agent_job.py list / history [--days 7]
```

Python から（バッチに import。**呼ぶ側は必ず握りつぶしラッパーで包む** → driver_template.py）:
```python
import agent_job
jid = agent_job.start(title=..., project=..., agent=..., total=25, job_id="nightly-batch")
agent_job.progress(jid, cur=i, note=...)   # 呼ぶこと自体が heartbeat
agent_job.done(jid, summary=...) / agent_job.fail(jid, summary=...)
```

## 設計の要点（運用で確定済み）

- **job_id 明示指定＝バッチ種別ごとに1枠を上書き**。再起動で古い記録が置き換わる
- **状態と実績を分ける**: 状態=`<job_id>.json`（done/failed 7日・他30日で prune）／
  実績=`history.jsonl`（done/fail 時に1行追記・prune しない・確定済みへの再 done/fail は追記しない）
- history 1行 = `{job_id, result, title, project, agent, started, ended, dur_sec, cur, total, summary, note}`
  （時刻はUTC `%Y-%m-%dT%H:%M:%SZ`・dur_sec は事前計算済み int|null）。読み手は壊れた行を読み飛ばす
- **stale検知は最終更新の途絶**（既定30分）。heartbeat が粗いバッチ（1件が数十分かかる等）は
  `--stale-sec` を明示しないと健全でも⚠️誤警報になる
- progress はファイルが消えていても骨格を再生成する（prune や手動削除でバッチを殺さない）
- start 失敗時も driver は固定 job_id を渡し続ける＝progress の骨格再生成で自己修復

## バッチ配線の地雷（Windows日本語環境・全部実測）

1. **起動側 .bat に `set PYTHONIOENCODING=utf-8` を焼き込む**。cp932 起動だと子プロセス出力の
   U+FFFD が print できず、ログ関数ごとバッチが死ぬ（実害あり）
2. **スクリプト側にも** `sys.stdout.reconfigure(encoding="utf-8", errors="replace")` の自衛（二段構え）
3. **venv の Scripts\python.exe はシム**で実インタープリタを子として spawn する＝1バッチが
   python.exe 2プロセスに見える。「二重起動」と誤診しない（ランチャー側の二重起動ガードは別途有効）
4. **台帳呼び出しでバッチを絶対に殺さない**: import 失敗は None・呼び出しは try/except 握りつぶし・
   Ctrl+C（BaseException）でも fail を記録して running を残置しない
5. ライブボードの常駐 watcher は起動時のコードをメモリ保持する。**live_board.py を変えたら watcher 再起動**

配線の最小コードは `agent-graph/driver_template.py` を参照（このパターンをテンプレとする）。
