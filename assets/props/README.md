# props — 休憩室の小物（reports/office.html・S22）

ここに置いた絵は office.html にインライン埋め込みされ、休憩室（`config.local.json` `office.lounge`）の
コード内矩形描画と**差し替わる**。無ければコード内の仮描き（色付きの四角）のまま＝絵は後から1点ずつ足せる。
描き方の決めごと（画風・ドットの大きさ・色・確認のしかた・依頼の受け方）＝`../README.md`。

## 受け入れ仕様
- 透過 PNG（SVG も可）。`image-rendering: pixelated` で表示＝ドット絵向き。**表示箱（下表）に `meet` で収めて下揃え・中央寄せ**なので、縦横比は箱に近いほどよい（多少違っても欠けない）
- ドット絵なら **1 ドット＝4px 表示**を目安に（例: ソファは 30×14 ドットで描く）。床はライト（既定）＝ベージュのカーペット・白い壁／ダーク＝こげ茶のカーペット。**どちらでも浮かないよう輪郭線をつける**（S23 追記・配色テーマ追従は S22）
- ファイル名＝英小文字・数字・`_`・`-`（32 字まで）。下表の 5 点は決まった箱に収まる。**それ以外の名前も直下に置けば拾われる**（S24〜・追加の小物＝箱は PNG の大きさ・1 枚 400KB まで）。休憩室に出すには下の「置き場所」で id を足す

| ファイル | 表示箱 (px) | ドット目安 | 中身 |
|---|---|---|---|
| `sofa.png` | 120×56 | 30×14 | 2人掛けソファ（正面） |
| `table.png` | 56×50 | 14×13 | ローテーブル＋コーヒーカップ2つ（カップは上端） |
| `plant.png` | 36×70 | 9×18 | 観葉植物（鉢＋葉）。**各島の角にも 0.7 倍で置かれる** |
| `coffee.png` | 90×80 | 23×20 | カウンター＋コーヒーメーカー（湯気はコード側が上に重ねる＝カップは中央下） |
| `vending.png` | 60×104 | 15×26 | 自販機（正面・缶が見える） |
| `printer.png` | 176×100 | 44×25 | 業務用プリンタ（iX っぽい箱）。**右端に排紙トレイ**＝コード側が箱の左から 146px・上から 46px に 24×6 の白い紙を流す |

- 窓（昼・夕・夜で空が変わる）とホワイトボード（在席/未読の数字）は動くのでコード描画のまま（絵の差し替え対象外）
- 置き場: `assets/props/<名前>.png`（直下のみ。テーマ別の小物は未対応）

## 置き場所（S24〜・個人PC の配置モードを休憩室だけ移植）
- `config.local.json` の `office.lounge_props`＝`{"<id>": {"kind": "<絵の名前>", "x": 0, "y": 0, "scale": 1, "hide": false}}`。x/y＝休憩室の左上からの px（絵の左上）
- id が `sofa`・`coffee`・`vending`・`printer` なら標準の小物を動かす／隠す（`kind` 不要・ソファに座る💤・湯気・用紙もいっしょに動く）。それ以外の id は `kind` の絵を足す（`kind` 省略＝id と同名の絵）
- 画面で動かす: 見出しの「🪑 小物配置」→ ドラッグ（このブラウザの localStorage に保存）・Shift+クリックで隠す・「＋ 小物」で足す → 「📋 JSON をコピー」の文面を `office` に貼る → watcher 再起動。配置モード中は自動更新を保留
- 反映: `live_board.py --html --watch` が次の書き換えで拾う（絵を置いただけでは office.html の中身が変わらない時は、席の状態が動いた時に反映される。すぐ見たいなら watch を再起動）

## アシスタント（絵の作成）への依頼文の例
> `assets/props/` に休憩室の小物を6点、透過 PNG のドット絵で。1ドット=4px 表示。名前と箱の大きさは `assets/props/README.md` の表どおり。
> 床はライト（ベージュのカーペット）とダーク（こげ茶）の両方がある＝輪郭線つきでどちらでも浮かないように。既存キャラ（`assets/sprites/<テーマ>/`）と並んで違和感ない画風で。
