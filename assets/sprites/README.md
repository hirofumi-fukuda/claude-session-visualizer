# sprites — オフィス配置図（reports/office.html）のキャラ絵

ここに置いた絵は office.html にインライン埋め込みされる（ファイル参照切れは起きない）。
無ければコード内のピクセル絵（claude_sv/office.py の SPR/HS）が使われる。
描き方の決めごと（画風・ドットの大きさ・色・確認のしかた・依頼の受け方）＝`../README.md`。

## 受け入れ仕様
- 透過 PNG（SVG も可）。表示は 36×48px 相当に縮小。ドット絵なら 12×16〜24×32 がにじまない
- ファイル名（固定）:
  - `human.png` … 人間（最後に話しかけた席の横に立つ1人）
  - `agent.png` … エージェント共通（グレー1枚＝モデル色を色相で乗せる）
  - または `agent-opus.png` / `agent-sonnet.png` / `agent-haiku.png` / `agent-fable.png`（モデル別に描く場合・共通より優先）

## テーマ（サブフォルダ）
- `assets/sprites/<テーマ>/` に上と同じファイル名で置くと、office.html ヘッダ右の 🎨 プルダウンで切り替えられる（選択は localStorage・`?spr=<テーマ>` で URL 指定も可）
- 人間の候補が複数あるなら `human-2.png` `human-3.png` … → 「<テーマ>（人間2）」として別の選択肢になる
- 直下の固定名は「既定」。`samples/` は作業用（絵の正本 `themes/*.py` と生成 `gen.py`）で読み込み対象外

## 種類（トラック別）・モデル・ポーズ（テーマ内の拡張命名）
`agent-<種類>-<モデル>-<ポーズ>.png` まで細かく置ける。無い組み合わせは粗い方へ落ちる（例: ポーズ無し→`agent-<種類>-<モデル>`→`agent-<モデル>`→グレー `agent-<種類>` に乗算→`agent`）。
- `<種類>` … 動物やキャラの名前（英小文字。`opus` 等のモデル名・ポーズ名は使えない）。**トラック名のハッシュで固定割当**＝同じトラックはいつも同じ種類。`config.local.json` `office.sprite_variants`（{"トラック名": "種類"}）で固定もできる（例: 業務ハブだけ特定の種類）
- `<モデル>` … `opus` / `sonnet` / `haiku` / `fable` / `unknown`（無ければグレー版に赤 #c24b4b を乗算）
- `<ポーズ>` … `typing`（作業中）/ `idle`（待機）/ `wait`（許可待ち） / `rest`（💤 離席中）/ `clone`（🧩 影分身＝サブエージェント。印＋足元の煙。無ければ主の絵に落ちる・机の上に 0.67 倍・不透明度 0.8 で立つ・10/21）
- 人間は `human.png`（候補 `human-2.png`…）のまま

## 席ごとに別テーマ
`config.local.json` `office.sprite_track_themes`（{"トラック名": "テーマ"}）で、特定の席だけ別フォルダの絵にできる（例: `{"業務ハブ": "ninja"}` ＝ハブは忍者・他は画面のテーマ）。種類・ポーズの落ち方はそのテーマ内で同じ（無ければ `agent-<モデル>`→`agent`）。
