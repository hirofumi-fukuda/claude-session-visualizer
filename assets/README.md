# assets — 絵の制作の決めごと（デザイナーアシスタント）

office.html の絵（キャラ・休憩室の小物）を作る時の決めごと。席（セッション）が入れ替わっても、ここを読めば続きから描ける。
依頼は `SendMessage` で「デザイナーアシスタント」宛てに届く（10/16〜）。受け入れ仕様（ファイル名・表示箱・無い時の落ち方）は各フォルダの README が正本。

## 置き場
| フォルダ | 中身 | 受け入れ仕様 | 絵の正本 |
|---|---|---|---|
| `sprites/` | キャラ（人間・エージェント） | `sprites/README.md` | `sprites/samples/themes/<テーマ>.py`（描画と書き出し＝`sprites/samples/gen.py`） |
| `props/` | 休憩室の小物 6 点 | `props/README.md` | `props/samples/gen.py` の `PROPS` |

- office.html が読むのは直下とテーマのサブフォルダだけ。`samples/` は作業用で読まれない。`samples/out/` はプレビュー置き場（gitignore）
- PNG は生成物。直す時はグリッド（1 文字＝1 ドット）を直して `--install` で置き直す。PNG を直接塗ると次の生成で消える
- この assets/ に置くのは office.html の絵だけ。ほかの制作物の置き場は依頼元が決める

## 画風（共通）
- ドット絵の透過 PNG。**表示サイズと同じ大きさで焼く**＝倍率 1 で表示されるのでにじまず、コード側が上に重ねる絵（湯気・用紙など）とも px 単位で合う
- 外側 1px に薄い白フチ `RIM=(255,255,255,90)` を焼き込む。暗い床（こげ茶 `#3d3330`）に黒っぽい色が溶けないように
- 小物はさらに濃い輪郭線 `#2b2b33`（キャラの髪・靴と同じ黒寄り）で囲む。明るい床（ベージュ `#dccfb5`）では線で、暗い床ではフチで浮かない
- 色数は少なめ。1 色につき影を 1〜2 段（明→暗）。共通色＝`sprites/samples/gen.py` の `BASE_PAL`（肌・目・グレー・赤・黄・茶など）。小物の木＝`#d9a066`・`#b07a45`・`#7f5330`（天板・正面・影）

## ドットの大きさ
| 種類 | マス | 1 ドット | PNG |
|---|---|---|---|
| キャラ | 12×16 | 3px | 36×48 |
| 小物 | 小物ごと（ソファ 29×13 など・`PROPS` の grid） | 4px | 表示箱と同じ大きさ（絵は下揃え・左右中央） |

- 小物の方がキャラより粒が少し大きい（依頼の仕様どおり・10/16 了承済み）。島の角に 0.7 倍で置かれる植物はドットが少し不揃いになる（実寸では目立たない）

## キャラの色とテーマ
- モデル色＝`MODEL_COLORS`（Opus `#8a5cf6`・Sonnet `#3b82f6`・Haiku `#d4a017`・Fable `#f472b6`・不明 `#c24b4b`）。`claude_sv/office.py` の `MODEL_COL` と同じ値を保つ
- グリッドの `1` `2` `3` は予約＝モデル色の本体・影（黒を 30% 混ぜる）・ハイライト（白を 38% 混ぜる）。人間の絵には使わない
- テーマは `themes/<名前>.py` の 1 ファイル。必須＝`PAL`・`HUMAN`・`AGENTS`。種類×モデル×ポーズまで描くなら `SPECIES`・`BODY`・`ACCESSORIES`・`POSES`・`ANCHORS` も足す。手本＝`themes/animal.py`
- **キャラを増やす時は、どのテーマにも種類（`SPECIES`）として足してよい。新しいテーマを作る時も種類を持たせる（種類なしの 1 テーマ＝1 見た目は作らない）**（個人PC側 10/17 ふくちゃん決定→10/18 改訂・S24 で取り込み）。種類名は英小文字（ハイフンなし＝ファイル名を `-` で割って種類を取る）で、持ち物や形で見分ける
  - 10/18 に office・monster・samurai・slime・space・ff・robot・sentai にも種類を足した（個人PC 4fe502a・会社へは S24 で絵と themes/*.py を取り込み）。前の 6 テーマは `AGENTS` の 4 体をそのまま種類にした（`SPECIES` の層＝`AGENTS["opus"][1]` のように絵まるごと・`BODY` は空）。robot・sentai は今の 1 枚＋新しく 2 体。ポーズは手前の層だけ（typing＝ノート PC・wait＝「!」・rest＝鼻ちょうちん）
  - 種類を足すと、名指ししていない席の自動の割り当て（トラック名のハッシュ）がずれる。固定したい席は config の `office.sprite_variants` で名指しする
- `ASSIGN`（任意）＝書き出し名→描いたモデルの付け替え（`{"opus": "haiku", …}`＝agent-opus.png に haiku の絵を opus の色で。値 `'*'`＝`FALLBACK` のグレー版）。ninja は c3eea27 の差し替えの並びをこれで再現している。グリッドを入れ替えて直さない
- `KINDS`（任意）＝席の役目の目印。`ASSIGN` 後の各絵に層を重ねて `agent-<種類>-<モデル>.png`・`agent-<種類>.png` を書き出す（一覧＝`out/<テーマ>/sheet-kinds.png`・インストールはしない）。席への割り当て＝config の `office.sprite_variants`。手本＝`themes/ninja.py`（hub＝幟・scribe＝巻物・10/16）
  - 種類名にモデル名・ポーズ名（`opus`〜`fable`・`unknown`・`typing`・`idle`・`wait`）は使えない（gen.py が止める）
  - 人間は席の左に立つので、目印は右か横長に置く。グレー版（乗算前）でも目印はパレットの色のまま描く＝乗算でキャラ色に染まらない
  - `sprite_variants` で名指しした種類は、名指しの席にだけ付く（ハッシュで他の席に配られない＝office.py 0e05c86）

## 小物の位置合わせ
コード（`claude_sv/office.py` の drawLounge）が小物の上に重ねる絵があるので、グリッドをずらすと合わなくなる。座標は `props/samples/gen.py` の冒頭に書いてある（コーヒーの湯気→カップ、印刷機の用紙→排紙トレイ）。
- 絵に差し替えると、仮描きにあった点滅（コーヒーの LED・自販機のランプ・印刷機の画面の色）は消える。湯気と用紙は残る（10/16 了承済み）

## 確認のしかた
1. `samples/` で `python gen.py` を実行 → `out/` のプレビューを見る（小物は明暗両方の床に並べた `preview.png`）
2. `--install` で置く（キャラはテーマ名を付けて `--install <テーマ>`）
3. リポ直下で `python -X utf8 live_board.py --html` を実行 → `reports/office.html` を開く。`?theme=light` と `?theme=dark` で両方の床を見る（キャラのテーマは `?spr=<テーマ>`）
- `reports/` はトランスクリプト由来の情報を含むので、スクショも外に出さない（作業用の一時置き場に置く）

## 依頼の受け方
依頼に次の 4 つが揃っていなければ、描く前に依頼元へ 1 往復で聞き返す（10/16〜）。
